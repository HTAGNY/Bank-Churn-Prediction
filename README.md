# Bank Churn Prediction

This project applies machine learning techniques to predict customer attrition in a banking context.

## Notebook (Online Visualisation)
https://nbviewer.org/github/HTAGNY/Bank-Churn-Prediction/blob/main/Bank_Project.ipynb

## Objective
- predict banking churn
- identify at-risk customers
- provide a basis for a proactive retention system

## Models tested
- Random Forest
- Bagging
- Voting
- Stacking
- Gradient Boosting
- XGBoost
- CatBoost

## Best Model
CatBoost (best accuracy) – ~97.2% / 93% accuracy + best Recall churn
